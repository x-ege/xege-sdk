EGE 图形库

  EGE（Easy Graphics Engine），是 Windows 下的简易绘图库，面向 C/C++ 初学者。
  接口简单直观，无需了解 Windows 编程即可快速上手图形编程，适用于 C 语言教学
  和计算机图形学课程。免费开源（MIT License）。

  当前版本：25.11

支持的开发环境
  - Visual Studio 2017 ~ 2026（推荐）
  - CLion（配合 XEGE Creator 插件）
  - Visual Studio Code（配合 EGE 插件）
  - 小熊猫 C++（已内置 EGE）
  - Code::Blocks、Dev-C++、MinGW-w64
  - 支持 Linux/macOS 下 MinGW-W64 交叉编译

主要特性
  ★ 简单易用  接口设计直观，几行代码即可绘图
  ★ 功能丰富  支持图像读写（PNG/JPEG/BMP/GIF 等）、透明混合、旋转缩放、
              相机捕捉、文本绘制、鼠标键盘输入等
  ★ 高效渲染  预乘 Alpha 像素格式，优化的绘图管线
  ★ 免费开源  MIT License，欢迎参与贡献

简要使用说明

  #include <graphics.h>
  int main()
  {
      initgraph(640, 480);
      circle(200, 200, 100);
      getch();
      closegraph();
      return 0;
  }
